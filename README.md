# Simulatta

Protótipo (Fase 0) de um RPG de ação e simulação de vida espacial com estética *cassette futurism* / cyberpunk espacial.

## Como jogar

Abra `index.html` no navegador (Chrome ou Edge) e clique em **INICIAR**. Não precisa instalar nada.

| Tecla | Ação |
| --- | --- |
| Mouse | Câmera (a pé) / mira (nave) |
| WASD | Andar / acelerar e esquivar |
| Shift | Correr |
| V | Alternar 1ª / 3ª pessoa |
| E | Interagir |
| G / R | Mover / girar móvel |
| Clique / F | Atirar |
| Espaço | Freio de emergência |
| I | Inventário e garagem |
| P | Loja |
| Q | Contratos |
| Esc | Configurações |

O documento de design está em `documento_de_design_de_jogo_e_roteiro_t_cnico.md`, e as artes conceituais estão nas imagens `.jpeg`.
